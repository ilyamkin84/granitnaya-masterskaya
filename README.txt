Распакуйте содержимое архива в одну публичную папку и откройте index.html через HTTP или HTTPS.
Главная ведёт в constructor/ и single/. Все модели, шрифты и текстуры входят в комплект.
Прямая ссылка на прогулку: constructor/?section=plot&view=walk&environment=cemetery.
Крупный план цветника: constructor/?section=plot&view=planting&environment=cemetery.
Для кнопки рендера из Unreal подключите сервер к api/unreal/status и api/unreal/render относительно папки главной.
